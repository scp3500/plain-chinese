# Plain Chinese

中文回复怎么写才读得懂的规则集。

只管语言：动词位置、词怎么选、结构怎么排、表态怎么给。内容对不对、事实有没有核，属于写作者的活。规则用中文写，因为要治的毛病都是中文语境的——翻译腔、`进行 + 名词`、空壳标题、防御性免责。

## 目录

- `RULES.md` — 全部规则，四块加一份交付前清单

## 四块内容

- 原则：讲具体机制、去衬托句、动词回位、真术语、有判断就下判断
- 句子：长短句节奏、衔接词按需、垫话、减法边界、一句接话
- 排版：带序号标题、分点不套标签、篇幅、收尾、任务边界
- 翻译腔：is / have 的六种句法角色、中文侧判据、密度验收

## 用法

直接读 `RULES.md`。挂进提示词时整段塞进 system，或只取「原则」和「交付前过一遍」两节压成短版。

新增规则必须同时给坏例和好例。只写「要简洁」「要自然」这类方向词，加了等于没加。

规则冲突时按这个顺序取：表态直接 > 具体机制 > 句子节奏 > 排版形式。
